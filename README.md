## Project Description
This project implements a graph data structure in C# and provides functionality to find the shortest path between two locations.  
The program includes:

1. **Graph Data Structure** – Nodes store edges in an adjacency list.  
2. **Data Population** – Graph nodes and edges are populated from a provided JSON file (or hardcoded if JSON parsing is skipped).  
3. **Shortest Path Calculation** – Any shortest path algorithm (e.g., Dijkstra’s algorithm) is used to find the shortest path between two nodes.  
4. **Driver Program** – Prompts the user for a source and target location, validates input, and prints the path.  
5. **Testing** – Includes base and edge case testing documented with screenshots.
